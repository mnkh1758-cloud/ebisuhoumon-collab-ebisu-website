## 2. データをダウンロードする方法（ZIPファイル）
AI Studioの画面上から、すべてのソースコードをZIPファイルとしてダウンロードできます。

1. 画面右上にある **「Share」** または **「Settings（歯車アイコン）」** のメニューを開きます。
2. **「Export to ZIP」** または **「Download ZIP」** をクリックします。
3. パソコンに `ebisu-hp08.zip` のようなファイルがダウンロードされます。

## 3. GitHubへアップロード（エクスポート）する方法

### 方法A：AI Studioの機能を使う（最も簡単！）
1. 画面右上のメニューから **「Export to GitHub」** をクリックします。
2. ご自身のGitHubアカウントと連携し、リポジトリ名を入力して「Export」を押すだけで、自動的にアップロードされます。

### 方法B：コマンドライン（ターミナル）を使う場合
今回、GitHubへ一括でアップロードするためのスクリプトファイル `push_to_github.sh` を作成しました。
ローカル環境（ご自身のパソコン）で作業する場合は、ターミナルで以下のコマンドを実行してください。

```bash
# スクリプトに実行権限を付与
chmod +x push_to_github.sh

# スクリプトを実行してGitHubへアップロード
./push_to_github.sh
```

※ 初めてアップロードする場合は、事前に `git remote add origin <あなたのGitHubリポジトリURL>` を設定しておく必要があります。
